\# Project Statement



\## Project Title



Python Quiz Application



\## Problem Statement



Students need a simple way to practice basic Python and computer science knowledge through multiple-choice questions.



The proposed system provides a command-line quiz where users can answer questions and immediately receive their score and percentage.



\## Scope of the Project



The project is designed as a basic command-line quiz application.



The current scope includes:



\* Taking the user's name

\* Displaying multiple-choice questions

\* Accepting answers

\* Checking answers

\* Calculating the score

\* Displaying the final percentage



\## Target Users



\* College students

\* Beginners learning Python

\* Students who want to practice basic computer knowledge



\## High-Level Features



1\. User input

2\. Quiz question display

3\. Answer checking

4\. Score calculation

5\. Result display

6\. Basic testing
