\# Python Quiz Application



\## 1. Project Overview



Python Quiz Application is a simple command-line quiz program developed using Python.



The application asks multiple-choice questions, checks the user's answers, and displays the final score and percentage.



This project demonstrates basic Python concepts such as lists, loops, functions, conditional statements, input/output, and modules.



\## 2. Features



\* User name input

\* Multiple-choice questions

\* Answer checking

\* Score calculation

\* Percentage calculation

\* Basic input validation

\* Command-line interface

\* Basic testing



\## 3. Technologies Used



\* Python 3

\* Python lists

\* Functions

\* Conditional statements

\* For loops

\* Modules



No external libraries are required.



\## 4. Project Structure



\* `main.py` - Starts the quiz application

\* `questions.py` - Stores the quiz questions

\* `quiz.py` - Runs the quiz and checks answers

\* `result.py` - Displays the score and percentage

\* `utils.py` - Validates the user's answer

\* `test\_quiz.py` - Tests the answer validation function



\## 5. Requirements



\* Python 3.x

\* Command-line terminal



No additional packages are required.



\## 6. How to Run



1\. Open the project folder in a terminal.

2\. Run:



```text

python main.py

```



3\. Enter your name.

4\. Answer each question using A, B, C, or D.

5\. The final score and percentage will be displayed.



\## 7. Testing



The project includes `test\_quiz.py` for basic testing of the answer validation function.



Run it using:



```text

python test\_quiz.py

```
